# AUR

`PKGBUILD` is a non-publishing skeleton for `praxis-prime-git`. `build()` exits with an error so `makepkg` cannot produce an empty package by accident.

`praxis-prime-bin` waits on a real release tarball. Do not submit either name to the AUR yet. Whether Basecamp accepts a package into pkgs.omarchy.org is an open question (ARCHITECTURE §31).
