# Praxis

Default theme for Praxis Prime. Marble ivory in the light mode, a dark bronze ground in the dark mode, oxblood and bronze accents. Display type is Cinzel, used for the wordmark and headings. Body type is Inter. Code is JetBrains Mono.

## Colours

Light: background `#f6f1e7`, raised `#fffdf8`, text `#231c17`, muted `#5e5247`, accent `#7a1f1f`, accent text `#fff8ee`. Status: ok `#2f6b35`, warn `#8a5a00`, danger `#a3261d`. `borderStrong` and the focus ring meet 3:1 against both surfaces.

Dark: background `#14110f`, raised `#1e1a17`, text `#efe7da`, muted `#b3a894`, accent `#c08a3e`, accent text `#14110f`. Status: ok `#6fbf73`, warn `#e0b04a`, danger `#e0655a`.

Contrast level is WCAG 2.2 AA in both modes. Optional tokens are derived by the engine.

## Fonts

Cinzel, Inter, and JetBrains Mono are subset WOFF2 files from the `ofl/` tree of github.com/google/fonts. Each family is SIL Open Font License 1.1. The licence text is `assets/fonts/OFL.txt`. The package does not load fonts from a network.

## Ornaments

`assets/ornaments/meander.svg` is a thin Greek-key divider. `assets/ornaments/laurel.svg` is a laurel-and-shield watermark drawn at 4% opacity. There is no eagle and no fasces.
