# Dental Office

Fresh and reassuring. Mint and aqua, soft corners, rounded display type. There is no clinical imagery: no teeth, no tools, no chairs.

## Colours

The core colours are the Addendum A §1.7 pairs. `borderStrong` is the muted colour and `ring` is the accent. Both clear 3:1 on the background and on the raised surface, so they were not moved. `accentFg` is white on deep mint and the dark ground on the light aqua.

Light: background `#f6fbfa`, raised `#ffffff`, text `#12302c`, muted `#4a6661`, accent `#0f766e`, accent text `#ffffff`. Status: ok `#1b7a4b`, warn `#8a5a00`, danger `#b42318`.

Dark: background `#0d1b1a`, raised `#142826`, text `#e9f6f4`, muted `#9fc2bc`, accent `#5eead4`, accent text `#0d1b1a`. Status: ok `#86efac`, warn `#fcd34d`, danger `#f28b82`.

Contrast level is WCAG 2.2 AA in both modes. Optional tokens are derived by the engine.

## Fonts

Display is Nunito. Body is Figtree. Code is JetBrains Mono, the same subset file as `smf.praxis`, copied into this package. All three are SIL Open Font License 1.1, from the `ofl/` tree of github.com/google/fonts. The licence text is `assets/fonts/OFL.txt`. The package does not load fonts from a network.

## Shape

`radius` is 12. Density is `comfortable`. There is no ornament.
