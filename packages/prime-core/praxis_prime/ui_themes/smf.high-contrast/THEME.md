# High Contrast

An accessibility theme at WCAG 2.2 AAA. Surfaces are pure white in the light mode and pure black in the dark mode. Text, muted text, borders, and the accent are the opposite of the surface. The focus ring is a dark yellow (`#847022`) on white so it clears 4.5:1, and pure yellow (`#ffff00`) on black.

Body and display type are Atkinson Hyperlegible (regular and bold). Code stays in JetBrains Mono so measurements remain monospaced. Both families are SIL Open Font License 1.1. See `assets/fonts/OFL.txt`.

Status colours are darkened on white and lightened on black until each pair, including the status label on the status colour, clears 7:1. Non-text pairs (`borderStrong`, `ring`, `accent`) clear 4.5:1, which is stricter than WCAG 1.4.11.

Motion is `none`. The base size is 18px. The divider is a yellow meander. There is no watermark.
