# Classical

Great books and lamplight, in the WisdomForge line. Dark mode is the default: ground `#0a0a0f`, antique gold `#c9a96e`. Display is Fraunces. Body is Source Sans 3. Code is Source Code Pro. The Socratic prompt style belongs to a pack or a persona, not to this theme.

## Colours

The core colours are the Addendum A §1.7 pairs. `borderStrong` is the muted colour and `ring` is the accent. Both clear 3:1 on the background and on the raised surface, so they were not moved. Light-mode `accentFg` is the raised stone `#fcf8f0`, which clears 4.5:1 on the olive accent. Dark-mode `accentFg` is the ground `#0a0a0f` on the gold.

Light: background `#f5efe3`, raised `#fcf8f0`, text `#221d16`, muted `#5b5041`, accent `#5b6b2f`, accent text `#fcf8f0`. Status: ok `#3f6b2a`, warn `#7d5a00`, danger `#9b2c20`.

Dark: background `#0a0a0f`, raised `#13131a`, text `#f3eadc`, muted `#b5a48c`, accent `#c9a96e`, accent text `#0a0a0f`. Status: ok `#9cc28a`, warn `#d9b25f`, danger `#e57368`.

Contrast level is WCAG 2.2 AA in both modes. Optional tokens are derived by the engine.

## Fonts

Latin subset WOFF2 files from the `ofl/` tree of github.com/google/fonts. SIL Open Font License 1.1. The licence text is `assets/fonts/OFL.txt`. The package does not load fonts from a network. Source Sans 3 and Source Code Pro are the same subset bytes as Legal Office, copied here so this package stands alone.

## Ornaments

`assets/ornaments/capital.svg` is a geometric column capital used as the divider. There is no watermark and no figure.
